The chart computed CTR in the chart itself (aggregation code 7, formula over aggregates). Three other data sources defined CTR differently, so the catalogue classed the group `conflict` and the client chose clicks over impressions. The Omni measure is a ratio of the two sum measures, so it is correct at any level of detail. The tile on the migrated dashboard uses `web_sessions_daily.click_through_rate`; the Route C contract for `cd-ctr` maps column `ctr` to that field.
