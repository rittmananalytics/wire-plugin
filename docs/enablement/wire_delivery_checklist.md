# Training Delivery Checklist — Wire Framework Developer Onboarding

## Pre-Session (1 week before)

- [ ] Confirm session date, time, and format (in-person / remote)
- [ ] Send calendar invites with Zoom/Meet link and agenda
- [ ] Verify all participants have Claude Code installed (`claude --version`)
- [ ] Verify all participants have access to the `rittmananalytics/wire` GitHub repo
- [ ] Send pre-session materials: exercises workbook + quick reference card
- [ ] Ask participants to bring a real or sample SOW PDF they can use during exercises

## Pre-Session (1 day before)

- [ ] Send reminder with Zoom link and pre-read: `USER_GUIDE.md` Sections 1–3
- [ ] Test plugin install walkthrough in a clean environment
- [ ] Prepare the demo repo (`wire-training-demo`) with context.md pre-seeded
- [ ] Verify screen sharing setup
- [ ] Check slide deck renders correctly (Marp preview or export to PDF)

## During Session

- [ ] Start recording (with participant consent)
- [ ] Share exercises workbook link at the start of Part 2
- [ ] Monitor exercise timing — Exercise 3 (requirements lifecycle) tends to run long
- [ ] Note questions that come up during exercises for FAQ update
- [ ] At the end of Part 4, ask each participant to name the release type for their next real engagement

## Post-Session

- [ ] Share recording and slide deck within 24 hours
- [ ] Send follow-up email with:
  - Quick reference card PDF
  - Link to GitHub wiki User Guide
  - Office hours schedule
  - `#wire-framework` Slack channel invite
- [ ] Schedule follow-up office hours (1 week post-training)
- [ ] Gather feedback: ask three questions
  1. Which part of Wire do you feel most confident using now?
  2. What's the one thing you'd want more time on?
  3. What would you add to the training?

## Materials Checklist

- [ ] Session plan: `wire/docs/enablement/wire_developer_session_plan.md`
- [ ] Slides: `wire/docs/enablement/wire_developer_slides.md`
- [ ] Exercises: `wire/docs/enablement/wire_developer_exercises.md`
- [ ] Quick reference: `wire/docs/enablement/wire_developer_quick_reference.md`
- [ ] User Guide: `wire/dist/wiki/User-Guide.md` (or GitHub wiki)
- [ ] Demo repo with pre-seeded `context.md`
